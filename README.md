# Ecommerce React - Firebase

Este es un proyecto de ecommerce desarrollado con **React.js** y **Firebase** como base de datos. Es un proyecto académico con fines educativos, donde se ponen en práctica conceptos fundamentales del desarrollo Frontend y consumo de servicios en la nube.

## Tecnologías utilizadas

- **React.js**: Librería de JavaScript para construir interfaces de usuario.
- **React Router**: Para la navegación entre componentes.
- **Firebase Firestore**: Base de datos NoSQL utilizada para almacenar los productos.
- **Context API**: Para la gestión de estado global del carrito.
- **CSS Modules**: Para el estilo de los componentes.
- **Netlify**: Para el deploy del proyecto.
- **React Icons**: Librería de íconos utilizada en el carrito y otros componentes.



## Funcionalidades

- Listado de productos desde Firebase.
- Filtrado de productos por categoría.
- Agregar productos al carrito.
- Visualización del número de productos en el carrito.
- Página para finalizar compra.
- Loader durante la carga de productos.



## Installation


```bash
   git clone https://github.com/tuusuario/tu-repo.git
   cd tu-repo
   npm install
   npm run dev
```
